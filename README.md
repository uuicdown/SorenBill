## ✨ 功能

| 模块 | 功能 |
|------|------|
| 🏠 **首页** | 月度收支汇总 + 交易流水列表 + 分类图标 + 日期跳转 |
| 📅 **日历** | 月视图日历 + 每日支出预览 + 节假日标注 + 点击查看当天交易 |
| 💰 **资产** | 净资产总览 + 26 家银行 + 微信/支付宝/网贷分组 + 余额修正 + 钱包切换 |
| 📊 **统计** | 饼图分类占比 + 月份切换 |
| ➕ **记账** | 金额优先输入 + 分类选择 + 账户/钱包 + 日期时间精确到分钟 |

## 🎨 设计

- 深灰主色调，克制低饱和配色
- 27 个银行/支付平台官方图标（来自官网 favicon）
- 34 个分类配有 Material 图标
- 统一的圆角、间距、字号规范

## 🛠 技术栈

| 层面 | 选型 |
|------|------|
| 语言 | Kotlin 2.2.10 |
| UI | Jetpack Compose + Material 3 |
| 数据库 | Room 2.7.1 + KSP |
| 架构 | MVVM + Repository |
| 构建 | Gradle 8.5 + AGP 9.2.1 |
| 最低 SDK | 26 (Android 8.0) |
